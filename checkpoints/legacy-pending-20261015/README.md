# Legacy pending drafts

These sanitized patches and the diagnostic transport module preserve divergent
local work for review. They are not applied to the current application and have
not been integration-tested as a set. Patch filenames identify their source task;
private absolute paths, host identities and network addresses are replaced.

The older desktop/voice-jobs/websocket modules and desktop test draft are superseded
by the already published consolidated bridge. The store exception patch and the
idle-disconnect correction/setup tests already occur in the prior checkpoint and
are not duplicated. Unique design plans are retained under docs/superpowers/plans.
Do not replace the current implementation wholesale with an older patch target.
The original worktrees remain unchanged for any later integration decision.
